# Pump Selection and Cavitation

A study hub for **Thermal Fluids**: how centrifugal pumps work, how to read a pump curve, how to select a pump for a pipe system, and how to keep it from cavitating.

> **For class teaching purposes only.**
> Source: Penoncello, *Thermal Energy Systems: Design and Analysis*, 2nd ed. These materials support the Thermal Fluids course and are not for redistribution or commercial use.

## ▶ Start here: open the interactive learning hub

**https://vdurgesh-lab.github.io/pump-selection-and-cavitation/**

The hub walks you through six modules in order, with links that open the lecture slides at the right page, jump straight to the right animation chapter, and point you to the matching example problem. The animations only run from the hub link above (GitHub shows `.html` files as code when you click them in the file list).

## How to use these materials

1. **Watch** the animation chapters for a module to build a picture of what is happening.
2. **Read** the lecture slides listed for that module.
3. **Try** the example problem on paper before opening the solution.
4. **Check** your answers against the worked solution.

## A note for first-time learners

- The NPSH safety margin appears in more than one form: the lecture slides recommend NPSHa − NPSHr ≥ 3 ft, while the Example 3 solution uses a 1 m safety factor. Use the margin a problem gives you, or ask your instructor.
- The slide numbers printed inside the *Pumps and Pump Performance* animation (134–148) refer to the textbook's slide set (*Thermal Energy Systems: Design and Analysis*, 2nd ed., Penoncello), not to the lecture PDF here. The matching lecture pages are listed in Modules 1–2.
- The cavitation animation uses an illustrative pump. Use manufacturer curves for real design work.
